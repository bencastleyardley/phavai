Operating loop

Weekly AI-assisted workflow

Use this loop to keep the site improving while the public pages stay evidence-first and commercially clean.

npm run growth:auditRefresh source, affiliate, and product intelligence reports.
npm run performance:import -- --ga-events <file> --amazon-tracking <file> --start YYYY-MM-DD --end YYYY-MM-DDLoad matched GA4 and Amazon reports for the monthly conversion snapshot.
npm run build && npm run quality:audit && npm run seo:auditBuild and run the non-browser quality checks.
npm run deployRegenerate the queue, build, and ship production through Vercel.
